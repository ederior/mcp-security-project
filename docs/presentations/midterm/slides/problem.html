Background, motivation and the gap. The agent mixes trusted instructions with untrusted data, and it acts with the user's authority. Each click adds one family. Prompt injection: the model follows instructions wherever they appear. Session hijacking: the session ID is treated as proof of identity, or a copied request is accepted again. Credential leakage: a secret the agent was allowed to read ends up somewhere it should not. Our threat model lists 15 threats across these families; we chose six core attack variants, two per family. Last click, the gap, desired versus actual: the sources on the literature slide recommend controls but give no numbers on how much each one reduces attack success. That is what we measure.
