The central idea: one harness runs every attack under every defense mode, so the results are directly comparable. Build it click by click. A scenario is a small data file, not code: which attack, which defense mode, and an explicit list of what the user is allowed to do. The harness runs it. It asks an AI model what to do next: either a scripted model that always answers the same way, used in every automated test with no internet or API key, or Google's Gemini, used only in manual experiments. Every action the model wants to take passes through the defenses before it reaches the MCP tools. Everything is written to an event log, so outcomes come from recorded events, not from reading the model's text. Three modes: none has no defenses, detect only raises alerts, full defense also blocks.
