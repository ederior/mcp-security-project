Define the terms before using them. Agent: an AI model (LLM) that can act by calling tools. Tool: a function the agent may call, such as reading a note. MCP, the Model Context Protocol: an open standard for how agents connect to tool servers. Walk the four boxes left to right. Click: the orange return path appears. Whatever a tool returns is read by the model as part of its input. Click: the warning. If an attacker controls any of that data, they are talking directly to the model.
