9

Each defense has a detector, which raises an alert, and a mitigation, which enforces. One per click. Injection (PI1a, PI2a, and CL2a's injected note): text rules flag override phrases, and an explicit tool policy blocks any call outside what the user asked for, before it runs. Sessions: a validator checks the request's user against the session's owner (SH1a), and a per-session list of used one-time numbers ("nonces") rejects a copied request (SH3a). Secrets: a scanner finds the registered fake secret at every exit point (answer, tool arguments, logs, result files) and a redactor replaces it. Code IDs if asked: prompt_injection_rules_v1, tool_authorization_policy_v1, session_binding_validator_v1, replay_validator_v1, synthetic_secret_scanner_v1, synthetic_secret_redactor_v1. Last click: session checks are protocol facts, never decided by an AI; the planned LLM judge will only advise. Known limits if asked: an instruction hidden inside quotation marks evades the text rules, though the tool policy still blocks the call; PI2a- and CL2a-specific rules are still open.
