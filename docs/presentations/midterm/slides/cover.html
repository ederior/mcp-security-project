Opener: we built a local lab that attacks an MCP-based AI agent the way an adversary would, then measures how much each defense helps. The animation on the right is the whole project in one loop: the agent sends a normal request (blue), a poisoned response comes back (orange), and a defense stops it before it reaches the agent. Since the July checkpoint, all six core attacks and a defense for each are implemented and tested on a scripted model. This talk shows what exists, what the first results mean, and what is left before the final. [Before presenting: drop the ECE faculty and Technion logo files into the two frames at the top left.]
