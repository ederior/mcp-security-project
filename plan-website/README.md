# אתר תוכנית העבודה

אתר RTL בעברית המסכם את מצב פרויקט MCP Security, חלוקת העבודה בין נעם לאור, שלבי הביצוע, חוזי האינטגרציה ושערי האיכות.

## אפשרות עצמאית ללא התקנה

פותחים את `index.html` ישירות בדפדפן. הקובץ כולל בתוכו את העיצוב והאינטראקציות ואינו דורש Node.js או שרת מקומי.

## הרצה מקומית

```powershell
pnpm install
pnpm run dev
```

לאחר מכן פותחים את `http://localhost:3000`.

## בדיקות לפני העלאה

```powershell
pnpm run lint
pnpm run build
```

אין להעלות את `node_modules`, את `dist` או קובצי סביבה. הם כבר מכוסים על־ידי `.gitignore` המקומי.
