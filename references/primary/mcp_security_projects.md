# MCP Security Community Projects and Threat Taxonomy

- **Original source:** https://modelcontextprotocol-security.io/projects/
- **Classification:** Primary supporting prior art; community maintained
- **Project snapshot summarized:** 2026-06-24

## Relevant Guidance

The community taxonomy groups MCP risks into areas including prompt and tool
injection, credential or API-key exposure, conversation-data compromise,
authorization failures, and session hijacking. It provides supporting evidence
that the three core families selected for this simulator correspond to concerns
recognized in wider MCP security work.

## Use in This Project

- Supports the prompt-injection, session-hijacking, and credential-leakage family
  structure.
- Provides prior-art language for the report and presentation.
- Identifies additional held variants such as tool-description poisoning, which
  are not part of the six core attacks.

## Limits

This is community-maintained prior art. Claims in the final report should pair it
with official MCP or OWASP guidance where possible.
